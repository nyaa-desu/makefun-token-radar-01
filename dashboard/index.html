How the value is computed

A protocol records no token when its DefiLlama record carries no market cap, no CoinGecko id and no symbol. That is the record's word, never proof it has none. Wrapped, staked and bridged products of a token that already trades, centralised exchanges and versioned pools are not ranked: a wrapped product is not a token that does not exist yet.

Implied value is this radar's own claim, never make.fun's, and it does not predict whether or when a token is issued.
